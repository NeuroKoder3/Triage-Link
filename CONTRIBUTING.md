# Contributing

**This project does NOT accept external contributions.**

TriageLink is proprietary software developed and maintained solely by
[NeuroKoder3](https://github.com/NeuroKoder3). Pull requests, patches, and
code submissions from external parties will be rejected without review.

## Reporting Issues

If you have been granted evaluation access and encounter a bug, you may
open a GitHub Issue to report it. Bug reports should include:

- Description of the problem
- Steps to reproduce
- Expected vs. actual behavior
- Screenshots (if applicable)
- Your environment (OS, version)
